# 💻 Hero Landing Page using Tailwind CSS- Task- 22

A modern Hero Landing Page built using Tailwind CSS (CLI). This project demonstrates clean UI design, responsive layout, and component-based styling using utility-first CSS.

---

## ✨ Features

- Sticky Header with Navigation Bar
    - Logo "Project" on the left
    - Links and CTA button on the right
- Hero Section with Gradient Background
- Call-to-Action Buttons
- Dashboard Image Preview
- Floating Task Cards (UI Components)
- Font Awesome Icons Integration
- Chat Button (Fixed Position)

---

## 🛠️ Technologies Used

- HTML5  
- Tailwind CSS  

---

## 🎯 Concepts Practiced

- Used positions utilities: `sticky`, `relative`, `absolute`, `fixed`  
- Used spacing utilities: `p-`, `m-`, `px-`, `py-`, `ml-`
- Used color utilities: `bg-`, `text-` 
- Used z-index `z-`
- used flex utilities: `flex`, `justify-`, `items-`  
- Used boarder utilities: `border-b-` 
- Used `&nbsp;` for spacing 
- Used shadow utilities: `shadow`, `shadow-black`

---

## ▶️ How to Run

1. Clone or download this repository  
2. Open `index.html` in your browser  

---

## 🎓 Purpose

To practice and showcase Tailwind CSS skills by building a real-world landing page with a modern UI and responsive design.
